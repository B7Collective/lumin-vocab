# Word bank pipeline

Rebuilds `public/data/words.json`.

1. Download sources into `data-src/`: Open English WordNet 2024 XML (`english-wordnet-2024.xml.gz` from the globalwordnet/english-wordnet GitHub releases), `cmudict.dict` from cmusphinx/cmudict, and the LDNOOBW `en` list. Install `wordfreq` with pip.
2. `python3 parse_oewn.py data-src/oewn.xml.gz oewn.pkl`
3. `python3 build_words.py` (filters and ranks WordNet candidates)
4. `python3 assemble_v3.py` (version 3, six levels). Hand-written sources: `kids_*.txt` (Sprout, Explorer), `advanced/scholar_*`, `wordsmith_*`, `academic_*`, `philosopher_*` (one entry per line: `word|part of speech|definition|example|topic`), `funny.txt`, side trails in `trails/` (first line `# key|Name|blurb|all, teen or adult|default level|default topic`, then bare words already in the bank, `word ~ partner` for mix-ups, or full entries `word|pos|definition|example|topic|level|~partner`), second example sentences in `sentences/` (`word|sentence`; files that sort later win), `topics.txt` and `levels.txt` for hand sorting, `beautiful.txt` and `funny_tags.txt` (bank words added to the Beautiful and Funny collections, so both have words at every level). Version 3.2 added `v4/<level>_<nn>.txt` (`word|pos|definition|example|second example|topic`): about 3,400 new words, each written for the level in its file name, picked with help from the CEFR-J Wordlist 1.5, the Octanove C1/C2 profile and Open English WordNet (see CREDITS.md), and checked so every word is a real dictionary word, both examples use the exact word, and nothing unsafe gets in. These words keep their level; the older Scholar to Philosopher words are re-sorted around them by how common they are, so each level is harder than the one below and all four end up about the same size. `funny.txt` entries may add a sixth field for level. Writes `words.json` and `trails.json`. An optional argument moves Wordsmith words rarer than that frequency up to Philosopher (default 1.9). Earlier versions: `assemble_v2.py`, `assemble.py`.

All hand-written lists, including `advanced/*.txt`, use `word|part of speech|definition|example|topic`, one per line. Edit them freely; keep examples family-safe and free of real people's names.
